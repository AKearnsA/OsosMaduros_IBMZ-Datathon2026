Retrospective replay with real daily REData data (peninsular system, 2025). Each forecast is computed from the previous day's data. 28-04-2025 is not used as model input because its data is distorted by the blackout itself. Inertia and RoCoF are physical estimates derived from the generation mix, not measurements. GridZ Shield is a decision-support tool: it does not control the grid.
